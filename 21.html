트라이와 페이즈의 구분

 

트라이는 단순한 연습, 페이즈는 하나의 대단원 !

트라이 파티와 페이즈 파티를 종종 헷갈려하시는 분들이 계시기에,
페이즈 = 여러 기믹을 하나로 묶은 것을 의미합니다.
토벌 대상마다 다르지만, 보통 특정 기믹 / 외형 변화 / 배경 변화 등을
기준으로 잡아서 진행하는 경우가 많습니다.

트라이 = 단순히 연습을 지칭하는 말로, " 개별 기믹 연습 " 에도 사용하는 말

ex)  3페트 = 3페이즈를 통채로 트라이 한다. 
       3페 춘식 트라이 = 3페이즈에 속해있는 "춘식" 이라는 기믹을 트라이한다.
 

클리어 파티에 들어가기 전! 

 

반드시 상자를 확인해서 들어가자 ! 

파판의 경우 현역 "영웅" 난이도의 경우 "주제한" 이라고 해서 
주마다 클리어 인원수에 따른 보상 상자수 제한이 존재합니다.
해당 층의 클리어 직후부터는, 자신이 상자 입찰에 실패했더라도,
화요일 오후5시 초기화 전까지는, 자신의 보상권이 없습니다.
따라서, 자신이 이번주에 클리어를 이미 한 상태라면,

[2상] 이라고 적힌 파티에는 절대로 들어가서는 안됩니다.

[ 2상 ] = 8명 모두 "이번주에 해당 층을 한번도 클리어 하지 않은 상태 "
[ 1상 ] = 4명이상 "이번주에 해당 층을 한번도 클리어 하지 않은 상태 "

또한,  1,2,3 층을 거치지 않고 4층부터 들어가게 되면,
입장 즉시 1,2,3층을 클리어 했다고 판정되기에 아래층 보상이 필요하다면
반드시 순차적으로 입장하도록 합시다.

외생기

공대 생존기
공생기
다음에 오는 기믹이나 페이즈를 효과적으로 넘어가기 위해서, 쿨이 돌아온 기술을 바로 사용하지 않고 모아두는 것을 의미한다. 자원의 뜻 자체는, 말 그대로 화력이 높은 기술 혹은 논글쿨 기술을 말한다.
자원
자원

버스트
버스트

시너지
시너지

자주 쓰는 기믹 용어

토벌 대상마다 시전하는 기믹 이름은 다르지만, 처리법이나 기믹의 형태가 같아서 보편적으로 부르는 단어

국룰 산개

12시 (A징) 을 기준으로, 가장 많이 사용하는 산개 기믹에 따라 산개는 매번 다르지만, 국룰대로 산개해라 라는 말은 위 사진처럼 산개하라는 의미이다.

국룰 조

가장 많이 사용하는 조 편성. 12시를 기준으로 오른쪽이 섭탱조, 왼쪽이 멘탱조 위/아래로 조를 나누는경우 위가 멘탱조, 아래가 섭탱조

카탈라이즈

카탈이라고 주로 부른다. 보스가 특정 방향을 향해 일직선으로 움직이며 공격하는 것.

엑사 플레어

엑사라고 주로 부른다. 서서히 다가오는 장판 기믹을 말한다.

채리엇

보스 주변에 깔리는 장판을 말한다. 회피 방법이 장판 밖으로 나가는거라, 대부분 “밖“ 이라고 말한다.

다이나모

보스 기준의 도넛 모양 장판을 말한다. 회피 방법이 안쪽으로 들어가는 거라 대부분은 “안“ 으로 말한다.
