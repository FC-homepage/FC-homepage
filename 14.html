추천 설정(기본 설정)

HUD 설정이 아닌,  몇가지 파판을 즐기는데에 있어 해두면 편하고 좋은 기능 설정들이 있습니다.
가급적 해당 추천 설정페이지에 있는 기능들을 이용해주시기를 권장드립니다.
 

캐릭터 설정

조작 방식&동영상 건너뛰기

ESC -> 캐릭터 설정 -> 조작 설정 -> 일반 -> 이동 조작 방식 설정을 카메라 고정으로 변경(키보드 유저 한정) 및
동영상 건너뛰기 설정을 통해, 갔던 장소의 동영상을 반복적으로 보지 않을 수 있습니다. 


캐릭터 설정

전투 효과 설정

ESC -> 캐릭터 설정 -> 조작 설정 -> 캐릭터 -> 전투 효과 설정에서 자신을 제외한,
파티원의 전투 효과는 간략 표시로, 기타 플레이어는 표시 안함으로 설정해둡니다.
해당 설정을 통해 과도한 전투 이펙트가 시야를 가리는 것을 방지 할 수 있으며,
육안으로 확인해야하는 파티원의 이펙트는 확인이 가능하기에 전투 진행이 용이합니다.


캐릭터 설정

불필요한 팝업창 끄기

ESC -> 캐릭터 설정 -> 사용자 인터페이스 설정 -> 일반 탭으로 들어가,
추천 임무, 공식 가이드, 업적 자동 표시를 꺼줍니다.
로그인 혹은 지역 이동 시마다 뜨는 불필요한 팝업창을 없애줍니다.


캐릭터 설정

(필수) 대상 백분율 표시

ESC -> 캐릭터 설정 -> 사용자 인터페이스 설정 -> HUD -> 대상에서 
" 대상 HP 백분율 표시 " 를 반드시 체크해주세요.
보스의 체력바를 % 단위로 보여주는 기능으로, 앞으로의 고난도 컨텐츠 이상의 게임 진행에 무조건 필요한 기능입니다.


캐릭터 설정

아이콘 설정

ESC -> 캐릭터 설정 -> 이름표시 설정 -> 일반 -> 일반 설정에서 
이름 옆에 직업 아이콘 표시를 선택하면, 파티원의 직업 구분을 조금 더 편하게 할 수 있습니다.



역할 가이드

레벨링 딜사이클의 경우 만렙이 아닌 이상은 연계 기술을 제대로 치고, 논 글쿨기를 쿨마다 사용하는 것 만으로도 레벨링이 충분히 가능합니다.
따라서 만렙이후, 딜사이클은 부대 사이트 전투 -> 만렙 딜사이클 탭으로 이동하여 확인을 부탁드립니다.
해당 페이지는, 초보자가 자신의 역할군 (탱커,힐러,근딜,원딜,캐스터) 가 어떠한 역할이고, 어떤 정보들을 알고 하면 좋은지 개념적인 부분들을 설명한 가이드를 모아두었습니다.

7.0 자료를 포함하여 가이드를 작성 할 예정으로 해당 페이지는 추후 업데이트 됩니다.

적정 장비와 마테리아

장비를 자기 레벨대에 맞게 제대로 챙겨입는 것은 매우 중요합니다.
해당 페이지에서는 던전 및 토벌전 입장 전, 올바른 템을 갖추었는지 확인하는 법과, 
마테리아에 대해 안내합니다.

 step.1

입장 템렙과 장비 비교

먼저, 임무 찾기 기능을 통해 (U키) 자신이 입장하고 싶은 던전이나 토벌전의 참가 조건을 확인합니다.
던전 설명창을 아래쪽으로 드래그하면, 입장 가능한 평균 아이템 레벨을 확인 할 수 있습니다.
참고 사진에서는 휘페르보레아 조물원의 입장 템렙이 515레벨임을 알 수 있습니다.


입장하고자 하는 곳의 입장 레벨을 확인했다면, 이제 자신의 장비와 입장 레벨을 비교해야합니다.
초보자의 경우, 높은 확률로 캐릭터창(C키)을 열었을때 바로 보이는 템렙 (사진상 *658 이라 적힌부분) 만 입장 레벨을 넘기면 된다! 라고 생각하지만
자신이 입고있는 모든 장비가 입장 장소의 " 평균 아이템 레벨 " 과 동일하거나, 혹은 그 이상이여야 합니다.

*다만 신생(1~50LV)의 경우 악세사리는 레벨별 스텟차이가 적어(끽해야 2~3), 48레벨 던전이여도, 20레벨대 악세사리를 끼고 입장해도 무관합니다.


step.2

마테리아

먼저, 마테리아는 [ 만렙 ] 달성 후, [ 만렙 ] 장비부터 장착하는 것이 보편적입니다.
만렙을 달성 후, 해당 확장팩에서 사용하는 가장 최신의 마테리아를 장착하는 것이 대중적이며, 
고난도 컨텐츠 (극.절.영식) 에서는 마테리아를 필수로 장착합니다. 


또한, 하우징 내 마테리아 장인, 혹은 주요 도시 마테리아 장인들에게 마테리아 장착을 의뢰 할 수 있지만
가급적 초보자 가이드 -> 추천퀘스트 -> 편의기능 쪽에서 마테리아 관련 퀘스트들은 전부 클리어 해두시기를 바랍니다.

마테리아의 경우, 다양한 루트로 수급이 가능하나 (PVP,무작위 숙련자 던전,장터게시판에서 구입 등), 마물런을 통해 획득하는 것이 효율이 좋습니다.

마테리아의 경우 먼저, 주 스탯과 부 스탯이 무엇인지 알아야 합니다.

주 스탯

각 직업의 역할을 수행하는데 최우선 되는 스탯이자,
데미지 계산시의 기본이 되는 스탯으로서,
마테리아 장착을 통한 변화가 불가능하고,
상위의 장비로 교체하는 방식으로만 높일 수 있는 스탯.

부 스탯보다 우선시 되기에, 장비를 볼 때 
부 스탯보다는 주 스탯이 높은 장비를 입는 것이 좋다.

부 스탯

각 직업군들이 모두 가지고 있는 공통된 스탯이자, 마테리아를 통해 수치를 올릴 수 있는 스탯으로,
영웅 난이도 이상 전투컨텐츠를 즐길 경우 메인 페이지에 있는 BIS를 통해 마테리아를 장착하는것이 대중적이며,
일반 던전, 24인 레이드, 극 토벌전 정도의 컨텐츠를 즐길 사람이라면  극대>의지>직격 순으로 장착하는 것을 추천합니다.

추천 퀘스트

각종 편의 기능부터 시작해서, 던전,토벌전,딥던전,고대무기 던전 등 많은 부분들이 서브퀘스트를 통해 진행되니 시간날때 참고하여 진행해주시면 좋습니다 :D
또한, 맵의 파란색 느낌표 아이콘이 달린 퀘스트가 새로운 컨텐츠 오픈 or 풍맥 퀘스트로 이어집니다.
해당 페이지에 적힌 추천 퀘스트는, 어디까지나 파란색 퀘스트 중에서도 [열어두면 괜찮다] 싶은 퀘스트들을 모아둔 것이기에, 해당 사이트에 적혀있지 않은 파란퀘스트들도 가급적 꼭 진행하시는걸 추천합니다 :)

해당 페이지에 없는 퀘스트들 (단골, 우호부족 등) 도 많기에, 가급적이면 공식 홈페이지 가이드 퀘스트란을 들어가 살펴보시는 것을 적극 추천합니다.
